## 🎯 Про проєкт

Кредитний скоринг — ключовий інструмент ризик-менеджменту у фінтех- та банківському секторі. Головна мета — автоматизувати процес прийняття рішень щодо видачі кредитів та мінімізувати фінансові ризики фінансової установи шляхом класифікації клієнтів на платоспроможних і потенційно проблемних.

### Основні завдання:
1. Аналіз соціально-демографічних та фінансових характеристик клієнтів.
2. Обробка пропущених значень, аномалій та дисбалансу класів.
3. Побудова та порівняння класифікаційних моделей (від інтерпретованої логістичної регресії до градієнтного бустингу).
4. Інтерпретація результатів моделі (SHAP / Feature Importance) для пояснення рішень регуляторам та бізнесу.

---

## ⚙️ Основні етапи

1. **EDA (Exploratory Data Analysis):**
   - Дослідження розподілів цільової та незалежних змінних.
   - Виявлення кореляцій та мультиколінеарності.
2. **Feature Engineering & Preprocessing:**
   - Кодування категоріальних змінних (One-Hot Encoding, Target Encoding, WoE — Weight of Evidence).
   - Розрахунок інформаційної цінності (IV — Information Value).
   - Масштабування числових ознак (StandardScaler / RobustScaler).
   - Обробка дисбалансу (SMOTE / Class Weights).
3. **Моделювання:**
   - Baseline: Logistic Regression.
   - Ансамблі: Random Forest, LightGBM, XGBoost, CatBoost.
4. **Валідація та тюнінг гіперпараметрів:**
   - Stratified $K$-Fold крос-валідація.
   - Оптимізація параметрів за допомогою Optuna або Grid/Random Search.
5. **Інтерпретація та розрахунок Scorecard:**
   - Побудова скорингової карти (переведення ймовірності дефолту у бали 300–850).
   - Аналіз впливу ознак за допомогою SHAP-значень.

## 📊 Метрики оцінки

Для бінарної класифікації у кредитному скорингу використовуються:
- **ROC-AUC** — якість ранжування позичальників за рівнем ризику.
- **Коефіцієнт Джині ($Gini = 2 \times \text{AUC} - 1$)** — стандартна метрика в банківському ризик-менеджменті.
- **KS-статистика (Kolmogorov-Smirnov)** — максимальна відстань між розподілами дефолтних і недефолтних позичальників.
- **Precision, Recall, F1-Score, PR-AUC** — оцінка точності на незбалансованих класах.
